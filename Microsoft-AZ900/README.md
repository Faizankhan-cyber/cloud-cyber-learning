## Study rules

1. Use the official study guide as the source of truth for exam scope.
2. Treat prior course completion as exposure, not proof of exam readiness. Assess each objective before marking it secure.
3. Record quiz scores only after completing the quiz; do not estimate or backfill scores.
4. For practical Azure work, record the steps and evidence, and delete billable resources when they are no longer needed.
5. Revisit weak areas using targeted revision and practice questions. Aim for consistent performance across all three domains before booking the exam.
