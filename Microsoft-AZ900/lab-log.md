## Suggested low-cost practice menu

These are ideas, not completed labs. Add a row to the log only after doing the work.

- **Resource hierarchy:** inspect management groups, subscriptions, resource groups, and resource navigation in the Azure portal; avoid creating resources unless necessary.
- **Cost awareness:** use the Azure pricing calculator to estimate a small VM or storage scenario; save the assumptions and estimate.
- **Governance concepts:** study or safely test Azure tags, Azure Policy, and resource locks in a sandbox or non-production resource group.
- **Management tools:** compare portal, Cloud Shell, Azure CLI, and Azure PowerShell; run read-only commands where possible.
- **Monitoring:** inspect the purposes and relationships of Azure Monitor, Log Analytics, alerts, Application Insights, Azure Advisor, and Service Health.
- **Storage:** compare storage account types, access tiers, and redundancy options; use a learning sandbox if hands-on creation is needed.
- **Networking:** diagram a VNet, subnet, peering, VPN Gateway, and ExpressRoute scenario before deploying anything.

## Safe lab checklist

- [ ] Confirm subscription and region before starting.
- [ ] Check pricing and student-credit impact.
- [ ] Use the smallest practical configuration and shortest runtime.
- [ ] Never place secrets, access keys, or credentials in screenshots or Git commits.
- [ ] Verify the expected outcome.
- [ ] Delete temporary resources and confirm cleanup.
- [ ] Capture screenshots only when they provide useful evidence; redact sensitive details.
