Key Concepts
Azure DDoS Protection
DDoS attacks can be volumetric, protocol-based, or resource/application-layer attacks.
Azure DDoS Protection protects Layers 3 and 4.
It provides always-on monitoring and adaptive real-time tuning.
DDoS IP Protection and DDoS Network Protection are available.
DDoS Protection can be combined with WAF for layered protection.
Azure Firewall
Azure Firewall is a managed cloud network security service.
It provides stateful network and application-level filtering.
It supports SNAT and DNAT, threat intelligence, logging, and monitoring.
Azure Firewall has Basic, Standard, and Premium tiers.
Web Application Firewall
WAF provides Layer 7 application protection.
It helps protect against attacks such as SQL injection and XSS.
It uses the OWASP Core Rule Set.
WAF can be used with services such as Application Gateway and Azure Front Door.
Network Security
Network segmentation helps isolate resources and supports Zero Trust.
Azure VNets can be divided into subnets.
NSGs and Azure Firewall can be used to filter network traffic.
NSGs use inbound and outbound rules with priorities, ports, protocols, and allow/deny actions.
Azure Bastion
Provides secure RDP and SSH access to Azure VMs.
VMs do not need public IP addresses.
Access is provided through TLS over port 443.
It provides browser-based access through the Azure Portal.
Premium includes features such as session recording and private-only deployment.
Azure Key Vault
Used for secrets, keys, and certificate management.
Microsoft Entra ID handles authentication.
Azure RBAC or Key Vault access policies handle authorization.
Supports least privilege and Zero Trust principles.
Premium provides HSM-protected keys.
