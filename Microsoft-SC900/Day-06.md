### Microsoft Defender for Cloud

I learned that Microsoft Defender for Cloud is a **Cloud-Native Application Protection Platform (CNAPP)** that helps protect Azure, AWS, GCP, and on-premises environments.

I studied its three main pillars:

* **DevSecOps** - Securing applications and code during development
* **CSPM** - Finding and fixing cloud security weaknesses
* **CWPP** - Protecting cloud workloads

I also learned about security policies, security initiatives, the Microsoft Cloud Security Benchmark, security recommendations, Secure Score, Defender plans, AI security, and Defender for DevOps.

### Microsoft Sentinel

I first learned the concepts of **SIEM** and **SOAR**.

* SIEM collects and analyzes security events to help detect and investigate threats.
* SOAR connects security tools and automates security response.
* Microsoft Sentinel is Microsoft's cloud-native SIEM/SOAR solution.

I also learned how AI and machine learning can help with anomaly detection, alert correlation, alert prioritization, and reducing alert fatigue.

Finally, I learned how **Microsoft Security Copilot** can work with Microsoft Sentinel to support security investigation and response.

Important distinctions I learned:

* **CSPM = Posture**
* **CWPP = Workloads**
* **SIEM = Seeing and analyzing security threats**
* **SOAR = Automating security response**
* **Microsoft Sentinel = Security platform**
* **Security Copilot = AI assistant**

I also learned the difference between a policy, security standard, and security recommendation:

* **Policy** checks whether a rule is being followed.
* **Standard** provides security guidance or a framework.
* **Recommendation** identifies a security issue and explains how to fix it.
