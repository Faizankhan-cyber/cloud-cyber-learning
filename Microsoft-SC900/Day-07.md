## What I Studied

Today I continued **Part 3: Security Solutions** and started the final module, **Describe threat protection with Microsoft Defender XDR**.

I learned the basics of Microsoft Defender XDR and how it provides unified detection, investigation, and response across multiple security areas such as endpoints, identities, email, and applications.

I also learned the difference between **XDR, SIEM, and SOAR**:

* **XDR** connects security signals and protection across integrated security products.
* **SIEM** collects and analyzes security data from different sources.
* **SOAR** automates security workflows and response actions.

## Key Concepts

* **XDR:** Cross-product security protection, detection, investigation, and response.
* **SIEM:** Collects and analyzes security data from many sources.
* **SOAR:** Automates security workflows and responses.
* **Defender XDR:** Connects signals from different Microsoft security products to understand the bigger attack picture.
* **Microsoft Defender portal:** Central place for Microsoft security operations.
* **Safe Attachments:** Helps detect malicious attachments.
* **Safe Links:** Helps protect users from malicious links.
* **Explorer:** Used to investigate email-related threats.
* **Message Trace:** Helps follow an email's journey through Microsoft 365.
* **ZAP:** Removes malicious messages after they have already been delivered.
* **AIR:** Automated Investigation and Response.
* **Attack Simulation Training:** Safely simulates attacks to train users.
* **Security Copilot:** Provides AI assistance for investigation and response.
